# Smart Nation 🌍

Integrated Digital Transformation Platform.

## Features

- Digital Identity Generation
- QR Code Verification
- Smart City Reporting
- AI-Based Report Classification
- Admin Dashboard
- Data Analytics
- Arabic and English Interface

## Technologies

- Python
- Streamlit
- SQLite
- Pandas
- Plotly
- QR Code

## Run

pip install -r requirements.txt

streamlit run app.py
منصة رقمية متكاملة تهدف إلى دعم التحول الرقمي من خلال توفير الهوية الرقمية، والتحقق الإلكتروني باستخدام QR Code، وإدارة بلاغات الخدمات العامة، ومراقبة المشكلات الجغرافية عبر الخرائط التفاعلية، وتحليل البلاغات باستخدام تقنيات الذكاء الاصطناعي.
